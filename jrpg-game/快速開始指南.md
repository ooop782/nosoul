# 🎮 日式 RPG 冒險 - 快速開始指南

## ✅ 已完成內容

### 1. 遊戲程式碼
- `src/main.py` - 完整日式 RPG 遊戲引擎
  - 隨機地圖生成
  - 玩家角色控制
  - NPC 對話系統
  - 回合制戰鬥系統
  - 升級系統

### 2. 無版權資源（全部程式生成）
- **圖片資源**
  - `assets/icon.png` - 遊戲圖標（劍與盾設計）
  - `assets/tileset.png` - 地形圖塊集
  
- **音樂資源**
  - `assets/music/bgm_title.wav` - 背景音樂（30 秒循環）
  - `assets/music/sfx_attack.wav` - 攻擊音效
  - `assets/music/sfx_hit.wav` - 受擊音效
  - `assets/music/sfx_levelup.wav` - 升級音效

### 3. 安裝程式
- **Windows**: `installer.bat` - 一鍵安裝腳本
- **Linux/Mac**: `installer.sh` - 一鍵安裝腳本

### 4. 可執行檔案
- **Linux**: `dist/JRPG_Adventure` - 已編譯的可執行檔（35MB）

## 🚀 立即開始

### Windows 用戶
```cmd
:: 方法 1: 使用安裝程式（推薦）
雙擊 installer.bat

:: 方法 2: 手動安裝
pip install pygame numpy pillow
python src/main.py
```

### Linux/Mac 用戶
```bash
# 方法 1: 使用安裝程式（推薦）
chmod +x installer.sh
./installer.sh

# 方法 2: 直接執行已編譯版本
./dist/JRPG_Adventure

# 方法 3: 手動安裝
pip install pygame numpy pillow
python src/main.py
```

## 🎯 遊戲操作
| 按鍵 | 功能 |
|------|------|
| ↑↓←→ 或 WASD | 移動角色 |
| Z 或 Space | 確認/互動/開始 |
| ESC | 返回標題 |

## ⚠️ 關於 Windows .exe 檔案

由於當前環境是 Linux 系統，已生成的可執行檔 `dist/JRPG_Adventure` 是 **Linux 版本**。

**如需 Windows .exe 版本**，請在 Windows 電腦上執行：
```cmd
cd jrpg-game
pip install pyinstaller pygame numpy pillow
pyinstaller --onefile --windowed --name="JRPG_Adventure" src/main.py
```
執行後會在 `dist` 資料夾中生成 `JRPG_Adventure.exe`。

或者直接使用 `installer.bat`，它會自動安裝依賴並創建啟動捷徑。
